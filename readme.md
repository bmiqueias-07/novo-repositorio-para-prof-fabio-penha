# Atividade 02 - Configuração do Ambiente Java

## Parte 2.2 - Extension Pack for Java

Eu instalei no Visual Studio Code o **Extension Pack for Java**, da Microsoft, para ajudar no desenvolvimento e execução dos projetos Java.

## Parte 2.3 - Configuração do settings.json

Eu realizada a configuração do arquivo `settings.json` do Visual Studio Code para utilizar as ferramentas que estão localizadas na pasta:

`C:\dev\tools`

Foram configurados os caminhos do:

- Maven
- Git
- Git Bash Portable

Também configurei as variáveis `MAVEN_HOME` e o `PATH`.
